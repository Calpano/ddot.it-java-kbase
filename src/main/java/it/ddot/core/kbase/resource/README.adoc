= Package `it.ddot.core.kbase.resource`
:icons: font
// ddot.it/off

Concrete `IKnowledgeItemResource` variants: content attached to a knowledge-graph node or edge.
Usually created through the static factories on `kbase.IKnowledgeItemResource`.

.Hierarchy
* `AttachmentResource` -- a local file, on disk or inside an archive
** `AttachmentFileResource` -- a file on the local file system
** `AttachmentArchivedFileResource` -- a file within an archive; URL format `{file url}#{path within archive}`
* `InlineResource` -- content held in the resource itself
** `InlineTextResource` -- inline text
** `InlineBinaryResource` -- inline bytes
* `RemoteResource` -- content referenced by a remote URL
