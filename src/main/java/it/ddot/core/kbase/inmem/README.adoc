= Package `it.ddot.core.kbase.inmem`
:icons: font
// ddot.it/off

The in-memory implementation of the link:../README.adoc[`kbase`] API.

.Contents
Kbase:: `IKnowledgeBase`: a map of named `Kgraph`s plus the `@context` map.
Kgraph:: `IKnowledgeGraph`: nodes, edges and an SPO index. Structural mutations are `synchronized`, so concurrent writers
(e.g. the multi-threaded indexer) are safe; reads are *not* guarded -- callers must establish a happens-before barrier before
querying a graph that was written concurrently. Supports provenance-scoped removal (`removeBySource`).
Kitem:: Shared base of `Knode` and `Kedge`: label, JSON data, resource, source locations.
Knode:: `IKnowledgeNode`.
Kedge:: `IKnowledgeEdge`. Triple metadata is stored flat in the edge's `data` JSON, one key per relation, and read back via `meta()`.
Klabel:: `IKnowledgeLabel`, with its `Entry` (value, language).
DdotItBaseOnKbase:: `IDdotItKnowledgeBase` over a `Kgraph`. Prefix queries match "starts-with OR word-initials".
KbaseDiff:: Triple-level diff of two `Kgraph`s (`added`, `removed`). Metadata is compared as an ordered *list* of pairs,
sorted by relation, so repeated relations are not lost and storage order does not matter. `TripleValue.toDdotLine()`
renders a triple via `io.DdotWriter`.
